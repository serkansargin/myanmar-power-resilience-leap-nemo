# myanmar-power-resilience-leap-nemo

Data and model files for the article "Power sector resilience co-benefits of decarbonization under compound fuel price, supply and drought shocks in Myanmar" (Serkan Sargin, Hang Za Dal, Kensuke Yamaguchi, Leong Yuen Yoong, Noah Kittner, Energy, 2026, DOI to be added).

## Contents                                                                                               
LEAP_area/       LEAP model area (OEPP and OMAP pathways, stress-test scenarios)                        
input_data/      Hydro capacity factors (Ember), drought profiles, gas/LNG assumptions                  
results/         Generation, capacity, costs, unmet demand by scenario (xlsx)                           

## Software
LEAP version 2024.4.0.15 and NEMO (Julia) version 2.2.0 with the HiGHS solver.
